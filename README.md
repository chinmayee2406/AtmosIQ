# 🌦️ AtmosIQ — Climate Intelligence & Predictive Analytics

An end-to-end data science project analyzing historical weather patterns, detecting climate anomalies, and evaluating temperature forecasting models across five major Indian cities from 2000 to 2025.

## 🎯 Problem Statement
Historical weather data can reveal temperature trends, seasonal variations, and extreme weather patterns, but extracting meaningful insights requires systematic data processing and analysis. Comparing these patterns across cities and identifying unusual conditions can help make historical climate data easier to understand.

## 💡 Solution
AtmosIQ collects and processes historical weather data to analyze temperature and rainfall trends, detect unusual weather patterns, and evaluate machine learning models for temperature forecasting. An interactive dashboard presents the findings through visualizations and city-level comparisons.

## 🛠️ Tech Stack
- **Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Statistical Analysis:** SciPy, Statsmodels
- **Database:** SQLite
- **Visualization:** Plotly, Matplotlib, Seaborn
- **Dashboard:** Streamlit
- **Data Source:** Open-Meteo Historical Weather API
- **BI Visualization:** Tableau Public
